# ТЗ: Фильтры в разделе «Каталог магазинов»

## 1. Зачем

Сейчас в каталоге всего 3 фильтра — `Все / Сетевые / Независимые`.
Этого мало:
- пользователь не может быстро увидеть «куда сегодня выгодно сходить»;
- 30+ магазинов в одном списке утомляют пролистывать;
- нет поиска по названию/адресу;
- нет фильтра «только мои» прямо из каталога.

Хотим:
- быстро находить **актуальные сегодня** магазины (завоз, скидка, низкая цена);
- быстро сужать выборку по сети;
- искать руками по тексту;
- по желанию — менять сортировку.

---

## 2. Текущее состояние (для контекста)

**Файлы:**
- `keyboards/catalog_kb.py` — определены `FILTER_LABELS = {all, chain, indep}` и `CatalogCb(action, page, flt, shop_id)`.
- `data/repos/shops.py::list_shops(flt, limit, offset)` — простой WHERE по `chain_name IS [NOT] NULL`, сортировка `chain_name NULLS LAST, name`.
- `handlers/catalog.py::_render_catalog` — рисует кнопки магазинов + ряд фильтров + пагинацию.

**Данные, доступные по магазину:**
- `chain_name` (или NULL — независимый)
- `cycle_length`, `anchor_date` — есть цикл/нет
- `price_start`, `price_step` — известны цены/нет
- вычисляется на лету через `services/cycle.py` и `card_template.build_context`:
  - `day_in_cycle`, `price_today`, `today_event` (ARRIVAL / MIDDLE / MAX_DISCOUNT), `days_to_arrival`, `days_to_max_discount`, `price_emoji` (🚚 / 🔴 / 🟡 / 🟢)
- подписка пользователя — `subs.is_subscribed(user_id, shop_id)`.

## 3. Что добавляем

### 3.1. Новые фильтры по «фазе сегодня»

Один из самых полезных вариантов — фильтр «что сегодня интересного»:

| Код фильтра | Кнопка | Условие |
|---|---|---|
| `today_arrival` | 🚚 Сегодня завоз | `today_event == ARRIVAL` |
| `today_discount` | 💰 Макс. скидка | `today_event == MAX_DISCOUNT` |
| `cheap_now` | 🟢 Дешёвый день | `price_emoji == 🟢` (последняя четверть цикла) |
| `coming_soon` | ⏰ Скоро завоз | `days_to_arrival ≤ 2` |

Эти фильтры — взаимоисключающие с базовым `all`: активен ровно один.

> **Решено:** базовые фильтры `Сетевые` / `Независимые` убираем. Деление по сетям доступно через отдельную кнопку «🏷 Сети ▾» (см. 3.3) — пользователю в каталоге не нужно различать сетевые/несетевые сами по себе.

### 3.2. Фильтр «избранное»

| Код | Кнопка | Условие |
|---|---|---|
| `tracked` | ⭐  магазины | пользователь подписан |

Полезен, чтобы из каталога быстро глянуть только свои.
(Раздел «Мои магазины» останется отдельным — там другой контекст: уведомления.)

### 3.3. Фильтр по конкретной сети

Если в системе несколько сетей (Megahand, Smart, и т.д.) — кнопка-аккордеон:

- В строке фильтров: **🏷 Сети ▾**
- При нажатии — экран со списком всех чейнов, по которым в БД ≥ 1 магазина.
- Каждая сеть = отдельный фильтр. После выбора возвращаемся в каталог, активен `chain:<name>`.

### 3.4. Поиск по тексту

Кнопка **🔍 Поиск** в строке фильтров →
- запускается FSM `CatalogStates.searching`,
- бот отвечает: «Введи название или часть адреса. Отменить — /cancel»,
- юзер шлёт текст → ставим `flt=search:<query>`, рендерим каталог с условием `name ILIKE %q% OR address ILIKE %q%`.
- Активный поиск отображается отдельной строкой над списком: `🔍 «<query>»  ✖️ сбросить`.

### 3.5. Сортировка (опционально)

Кнопка **↕ Сортировка ▾** → экран выбора:
- По названию (default)
- По дню завоза (недавние завозы сверху: сегодня → вчера → неделю назад → ...)
- По цене сегодня (дешёвые сверху, только магазины с известной ценой)

Сохраняется в `CatalogCb` отдельным полем `sort`.

## 4. UX / визуал

### 4.1. Раскладка кнопок (mobile-friendly)

```
[ магазин 1 ]
[ магазин 2 ]
…
[ магазин N ]
[ ◀️ ] [ 1/3 ] [ ▶️ ]                ← пагинация
[ 🔍 Поиск ] [ 🏷 Сети ▾ ] [ ↕ ▾ ]   ← вспомогательные
[ • Все • ] [💘 Ну мои]                ← база + избранное
[ 🚚 Завоз ] [ 💰 Скидка ] [ 🟢 Дёшево ] ← фильтры дня
[ ⏰ Скоро завоз ]
[ 🏠 В меню ]
```

Активный фильтр маркируется `• Текст •` (как сейчас).

### 4.2. Шапка над списком

```
🛍 Каталог секонд-хендов
Найдено: <b>12</b> · 🚚 Сегодня завоз

Нажми на магазин, чтобы открыть карточку
```

Вторая строка — динамическая: показывает выбранный фильтр + (если активен поиск) сам запрос.

### 4.3. «Пустой результат»

Если фильтр отсёк всё:

```
🛍 Каталог
Под фильтр «🚚 Сегодня завоз» ничего не подошло.

[ ✖️ Сбросить фильтр ] [ 🏠 В меню ]
```

## 5. Технические детали

### 5.1. Schema callback_data

Расширяем `CatalogCb`:
```python
class CatalogCb(CallbackData, prefix="cat"):
    action: str       # "list" | "shop" | "filter" | "search" | "sort" | "chain_pick"
    page: int = 0
    flt: str = "all"  # "all" | "today_arrival" | "today_discount" |
                      # "cheap_now" | "coming_soon" | "tracked" | "chain:<name>"
    sort: str = "name"  # "name" | "next_arrival" | "price"
    shop_id: int = 0
```

Поиск держим **в FSM-данных пользователя**, не в callback_data (длинные строки в callback не помещаются — лимит 64 байта).

### 5.2. БД vs Python

Часть фильтров — простые SQL (`chain`, `indep`, `chain:<name>`).

«Фазовые» фильтры (`today_arrival`, `today_discount`, `cheap_now`, `coming_soon`) требуют расчёта `day_in_cycle` от `anchor_date` — это можно либо:
- **(a)** делать в SQL через `((today - anchor_date) % cycle_length)`,
- **(b)** грузить кандидатов и фильтровать в Python.

Магазинов мало (десятки) — **выбираю (b)**. Проще тестировать, не нужно дублировать логику цикла в SQL.

`tracked` — JOIN с `subscriptions WHERE user_id = $X`.

### 5.3. Пагинация при «фазовых» фильтрах

Так как фильтр применяется в Python, считать `total` нужно после фильтрации. Загружаем все магазины (или из БД с `is_active=true`), фильтруем, режем по `PAGE_SIZE`. Это нормально при ~50 магазинов.

### 5.4. Производительность

- Кэшировать `list_shops()` целиком на 60 с (как `bot_config`) — рендер каталога становится дешёвым.
- На каждый рендер: 1 запрос за магазинами + 1 за подписками пользователя (для маркера ⭐ в кнопке).

### 5.5. Маркер дня в кнопке магазина

Уже есть `today_marker(shop, today) → 🚚 / 💰 / ⚖️`. Сохранить как сейчас — он не зависит от фильтра.

### 5.6. Тексты

Новые ключи в `services/texts.py`:
- `catalog.filter.<code>` — лейбл каждой кнопки
- `catalog.search.prompt` — «Введи название или адрес»
- `catalog.search.active` — «🔍 «{query}» · ✖️ сбросить»
- `catalog.empty_filter` — «Под фильтр ничего не подошло»
- `catalog.sort.<code>` — лейбл варианта сортировки

---

## 6. Что НЕ делаем (out of scope)

- Множественный выбор фильтров (`сетевые + сегодня завоз`). Один фильтр одновременно — проще и понятнее.
- Фильтры по геолокации/районам — пока в БД нет деления.
- Сохранение «любимого фильтра» в профиле — никто не просил.

---

## 7. Финальные решения

1. ✅ Фильтры дня — оставляем все 4 (`🚚 Завоз / 💰 Скидка / 🟢 Дёшево / ⏰ Скоро`).
2. ✅ Фильтры по сетям убираем полностью (ни `Сетевые/Независимые`, ни «🏷 Сети ▾»).
3. ✅ Поиск — нужен.
4. ✅ Сортировка — нужна (по названию / по дню завоза / по цене).
5. ✅ 💘 «Ну мои» в каталоге — оставляем.
6. ✅ Раскладку прячем за «⋯ Ещё фильтры» — основной экран короткий.
7. ✅ Отдельная кнопка «✖️ Сбросить» (показывается только если фильтр != «Все» или активен поиск).
