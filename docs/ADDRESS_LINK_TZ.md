# ТЗ: Адрес магазина в карточке как ссылка на Яндекс.Карты

## 1. Цель

Сейчас в карточке магазина адрес — обычный текст:

```
📍 ул. Победы, 12
```

Хотим: адрес — кликабельная ссылка, тап по которой сразу открывает
**Яндекс.Карты** на нужном месте (в приложении, если установлено,
или в веб-карте). Без копипасты, без поиска вручную.

---

## 2. Что Telegram умеет

Telegram (с `parse_mode="HTML"`) поддерживает кликабельные ссылки
через `<a href="...">текст</a>`. По тапу:
- На Android/iOS — Telegram спрашивает «Открыть в браузере?» и идёт по URL.
  Если у пользователя установлено приложение Яндекс.Карт — оно перехватит
  deeplink и откроет точку в нативном приложении.
- В Telegram Desktop — открывает URL в браузере по умолчанию.

---

## 3. Формат ссылки на Яндекс.Карты

Два варианта URL, выбираются автоматически:

### 3.1. По адресу (когда координат нет)
```
https://yandex.ru/maps/?text=<URL-encoded query>
```
Где query — `«Севастополь, <address>»`. Префикс города добавляется,
если он уже не присутствует в адресе (case-insensitive).

Пример:
- адрес: `ул. Победы, 12`
- URL: `https://yandex.ru/maps/?text=%D0%A1%D0%B5%D0%B2%D0%B0%D1%81%D1%82%D0%BE%D0%BF%D0%BE%D0%BB%D1%8C%2C+%D1%83%D0%BB.+%D0%9F%D0%BE%D0%B1%D0%B5%D0%B4%D1%8B%2C+12`

### 3.2. По координатам (когда добавим `latitude`/`longitude` — см. `GEO_FILTER_TZ.md`)
```
https://yandex.ru/maps/?ll=<lon>,<lat>&z=17&pt=<lon>,<lat>
```
Точная метка, без зависимости от качества адресной строки.

> Эта ветка появится одновременно с геофильтром или раньше — `services/maps.py`
> уже принимает опциональные `lat`/`lon`, чтобы не править места вызовов потом.

## 4. Что меняем

### 4.1. Новый модуль `services/maps.py`

```python
def yandex_maps_url(
    address: str,
    *,
    city: str = "Севастополь",
    lat: float | None = None,
    lon: float | None = None,
) -> str: ...

def yandex_maps_link_html(
    address: str,
    *,
    city: str = "Севастополь",
    lat: float | None = None,
    lon: float | None = None,
) -> str:
    """Вернёт `<a href="...">{escaped address}</a>`. URL-encoded + HTML-escaped."""
```

Чисто строковая функция, без сети. Покрывается юнит-тестами.

### 4.2. Контекст карточки

В `services/card_template.py::build_context` добавить новую переменную:

```python
ctx["address_link"] = yandex_maps_link_html(shop.address)
```

Старая переменная `address` остаётся (используется в других местах —
например, в `format_price_schedule`). Просто появляется новая опция.

### 4.3. Шаблон карточки

В `card_blocks.py::DEFAULT_BLOCKS` блок `address`:

**Было:**
```python
default_text="📍 {address}\n",
```

**Станет:**
```python
default_text="📍 {address_link}\n",
```

То же самое в `card_template.py::DEFAULT_TEMPLATE` — заменить `📍 {address}`
на `📍 {address_link}`.

### 4.4. Регистрация переменной в SA-панели

В `card_template.py::VARIABLES` добавить новую запись:
```python
("address_link", "Кликабельный адрес-ссылка на Яндекс.Карты"),
```

Чтобы суперадмин видел эту переменную в подсказке при ручной правке шаблона.
Старый `address` оставляем — для тех, кто хочет адрес без ссылки.

### 4.5. Совместимость

- Юзеры, у которых в БД лежит **старый сохранённый шаблон** (`shop_card_template`
  или `shop_card_blocks`) с `{address}`, — не пострадают: переменная `{address}`
  по-прежнему работает, просто без ссылки. Чтобы получить ссылку — обновить
  блок «Адрес» в SA-панели или нажать «Сброс к дефолту».
- Дефолтный шаблон (новые установки + те, кто не кастомизировал блок) —
  получит ссылку автоматически.

### 4.6. format_price_schedule

В `card_render.py::format_price_schedule()` адрес НЕ используется —
не трогаем.

### 4.7. Безопасность

- `address` приходит из БД, заполняется админом. Уже доверенный источник,
  но **обязательно**:
  - URL-параметр `text=` пропускаем через `urllib.parse.quote_plus`.
  - В HTML-аттрибуте `href="..."` экранируем через `html.escape(url, quote=True)`.
  - Внутри `<a>...</a>` сам адрес — через `html.escape(address)`.
- Защита от инъекции в БД-адресах (XSS, ломающие шаблон) уже работает —
  тест `test_user_value_with_dsl_syntax_is_not_evaluated` гарантирует, что
  подставленные значения не реевалюируются. Новая переменная `address_link`
  собирается тем же способом и под ту же защиту.

### 4.8. Edge-cases

| Кейс | Поведение |
|---|---|
| Адрес пустой строкой | Ссылка не строится — выводим `📍 {address}` (пустота). Лучше отдельной правкой запретить пустой `address` в админке, но это вне scope. |
| Адрес уже содержит «Севастополь» | Префикс города не добавляем (case-insensitive поиск substring). |
| Адрес содержит спецсимволы (`&`, `<`, кавычки) | `html.escape` + `quote_plus` справляются. |
| Адрес очень длинный (>200 символов) | Не обрезаем — Яндекс возьмёт первые ~100 символов сам и найдёт лучшее совпадение. |

## 6. Что НЕ делаем

- ❌ Альтернативные карты (Google, 2GIS) — Яндекс по требованию пользователя.
- ❌ Кнопка «Открыть в Яндекс.Картах» отдельной inline-кнопкой — это
  потенциально приятная фича, но обсуждается в `GEO_FILTER_TZ.md` (open Q #6).
- ❌ Авто-копирование адреса — Telegram даёт это бесплатно через долгий тап на ссылке.
- ❌ Превью карты (`<a>` URL → preview-картинка). Telegram сам решает, показывать
  ли превью; Яндекс.Карты обычно не отдают OG-картинку. Мы это не контролируем.

## 7. Открытые вопросы

1. **Город в query** — фиксированно «Севастополь» (рекомендую — бот про этот город),
   или вынести в `bot_config.city_for_maps`?

2. **Если пользователь не дал доступ открыть ссылку** (`Telegram Desktop` без
   браузера / запрет на открытие) — фолбэк нужен? Например, под адресом ещё
   inline-кнопка `📍 Открыть в картах`?

3. **Когда добавим координаты магазинов** (`latitude/longitude`) — переключиться
   на `?ll=` сразу же или оставить `?text=` пока админ не заполнит координаты?
   Рекомендация: автоматически использовать координаты, если заданы; иначе fallback на адрес.

4. **Превью ссылки** в сообщении (Telegram по умолчанию пытается подгрузить
   preview карты). Включить или подавить через `disable_web_page_preview=True`?
   Сейчас в `card_view.py` мы не управляем preview — стоит добавить
   подавление, чтобы не появлялась случайная картинка под карточкой.
